# Déploiement V53 — étape par étape

Cette archive est une **mise à jour** de votre dépôt PsyLab actuel. Ne supprimez pas les autres fichiers du dépôt.

1. Ouvrez le dépôt GitHub `teamsydz/PSYLAB`.
2. Ajoutez/remplacez les fichiers en conservant exactement leur arborescence.
3. À la racine, remplacez `index.html` et ajoutez `v53.css` + `platform-v53.js`.
4. Dans `courses/bipolar/`, remplacez `index.html` et `en.html`, puis ajoutez `v53.css` + `v53.js`.
5. Ne touchez pas à `psylab-config.js`.
6. Aucun script SQL V53 n’est à exécuter.
7. Attendez le déploiement Cloudflare Pages, puis testez d’abord en 4G puisque le problème Wi-Fi est volontairement reporté.

À vérifier après déploiement : page d’accueil, ouverture BipolarLab, carte « Tout le monde veut la blouse », pseudonyme du titulaire, Top 5, bouton du défi, défi en cinq étapes, version FR et EN, navigation mobile.
