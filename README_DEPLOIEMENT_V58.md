# Déploiement V58 prototype

1. Faites une sauvegarde de votre dépôt actuel.
2. Décompressez `PsyLab_V58_Prototype_Update.zip` à la racine du dépôt GitHub PSYLAB.
3. Remplacez les fichiers proposés.
4. **Ne remplacez pas `psylab-config.js`.** Il n’est pas inclus dans le package.
5. Aucune nouvelle migration Supabase n’est requise si V57 fonctionne déjà.
6. Attendez le redéploiement Cloudflare Pages.
